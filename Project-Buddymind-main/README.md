# Buddymind 🧠

Buddymind is my first Android Studio project.

I created this project while learning Android development. The main idea of the application is to encourage users to take mindful breaks and be more aware of their screen time.

## Features

- Screen time management
- Mindful break reminders
- Riddle-based activities
- Community section for sharing riddles
- Firebase-based data storage

## Technologies Used

- Kotlin
- Android Studio
- Firebase Firestore
- Git & GitHub

## About the Project

This was my first Android Studio project, so it was mainly created as a learning project.

While building Buddymind, I learned about Android application development, Kotlin, Firebase, and working with different Android features.

AI was also used as a development aid during the project.

## Project Status

This is an early learning project and is not intended to be a production-ready application.
